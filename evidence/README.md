# THƯ MỤC MINH CHỨNG

Thư mục này lưu minh chứng theo bảy nhóm Rubric. Xem `EVIDENCE_REGISTER.md` để biết chính xác file nào đã có, nguồn tạo và những mục còn thiếu.

- **TC1:** bản xem trước báo cáo đã có; ảnh chụp Word trên máy sinh viên chưa có.
- **TC2:** wireframe desktop/mobile dạng PNG đã có; bản SVG chỉnh sửa nằm trong `docs/wireframes/`.
- **TC3:** cần ảnh chụp VS Code và bốn trang website chạy trên trình duyệt Windows.
- **TC4:** cần ảnh Chrome/DevTools, form, menu và bảng test đã ghi kết quả thật.
- **TC5:** bản xem trước báo cáo đã có; cần kiểm tra, cập nhật và lưu phiên bản cuối trên máy sinh viên.
- **TC6:** cần video hoặc ảnh demo do sinh viên tự thực hiện.
- **TC7:** cần ảnh Repository, commit, GitHub Pages và URL hoạt động.

Không có ảnh kiểm thử trình duyệt hoặc GitHub giả trong gói. Các ảnh có tên `ReportPreview` là ảnh render trang tài liệu, không phải ảnh chụp thao tác từ máy cá nhân.
